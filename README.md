# Power BI Sales Analytics Dashboard

## Overview

This project is a multi-page Power BI dashboard built using the Superstore dataset.

The dashboard provides insights into:

- Sales Performance
- Profit Analysis
- Product Performance
- Customer Analysis
- Regional Analysis

---

## Dashboard Pages

### Executive Summary
- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Profit Margin
- Sales Last Year
- YTD Sales
- Growth %

### Product Analysis
- Top Products by Sales
- Top Products by Profit
- Category Analysis

### Customer Analysis
- Top Customers by Sales
- Top Customers by Profit
- Customer Ranking

### Regional Analysis
- Sales by Region
- Profit by Region
- Regional Performance Metrics

---

## Key Business Insights

- West region generated the highest sales.
- Consumer segment generated the highest revenue.
- Technology category generated the highest profit.
- September recorded peak sales performance.

## Tools Used

- Power BI Service
- DAX
- Power Query
- Superstore Dataset
